# Правила работы с файлом main.luajit

`main.luajit` — песочница пользователя для тестирования биндингов и
функционала движка. Структуру этого файла определяет только пользователь.

В рамках тестов файл может временно изыматься из проекта. Если его нет на
месте — это нормально и это временно.

## Разрешенные изменения

- Переименование переменных при изменении API
- Обновление имен модулей/функций для совместимости
- Исправление синтаксических ошибок
- Обновление вызовов функций при изменении сигнатур

## Запрещенные изменения

- Изменение структуры файла
- Изменение логики или порядка вызовов
- Добавление/удаление больших блоков кода
- Реорганизация секций
- Изменение стиля кодирования
- Любые "улучшения" без явного запроса пользователя

## Принцип работы

Только пользователь решает, как должна быть организована структура этого
файла. Агент должен делать только минимально необходимые изменения для
поддержания работоспособности кода при изменениях в API движка.
